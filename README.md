# Bouncerback
Bouncerback is a retro-inspired 2Dvideo game that challenges the player on speed, precision and concurrent attention.

Bouncerback uses simple vector graphics, minimal color palette and synthesized sound effects. The game is played by containing balls that spawn from the center of the screen and travel in random directions. The player needs to spawn paddles to contain the balls by touching or clicking on the screen in the general area where they want the paddles to appear. Those paddles appear in a ring drawn around the center of the screen and dissapear after a short time, so the player needs to spawn the paddles right before the balls are about to escape the containing ring.
